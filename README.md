# Video AI — запуск внутри ChatGPT

**Цель:** показывать созданную анимацию во встроенном окне ChatGPT с управлением воспроизведением и возможностью сформировать WebM.

[![Deploy to Cloudflare](https://deploy.workers.cloudflare.com/button)](https://deploy.workers.cloudflare.com/?url=https://github.com/olgakolina71-pixel/Videoai)

Нажми кнопку выше, войди в Cloudflare и подтверди развёртывание. Cloudflare развернёт Worker из этого публичного репозитория и создаст отдельную копию репозитория в твоём GitHub.

После развёртывания:
1. Скопируй адрес Worker вида `https://…workers.dev`.
2. MCP-адрес будет заканчиваться на `/mcp`.
3. В ChatGPT открой настройки приложений/коннекторов, включи режим разработчика, если он доступен, и добавь пользовательское MCP-приложение с этим адресом.
4. Назови приложение **Video AI** и выбери вариант без авторизации для этого прототипа.

Подробности и ограничения: [README-MCP.md](README-MCP.md).

> Эта версия создаёт процедурную 2D-анимацию из сцен, которые составляет ChatGPT. Она показывает встроенный предпросмотр и может записать его в WebM. Это ещё не генерация реалистичного видео из фото, не озвучка и не музыкальный редактор.
