# Video AI — текстовый MCP-инструмент

Эта экспериментальная версия убирает встроенный интерфейс, iframe, плеер и браузерную запись WebM. Она оставляет один текстовый MCP-инструмент `create_video_project`, который возвращает проверенную JSON-структуру 2D-сцены.

## Подключение

MCP endpoint: `https://<your-worker>.workers.dev/mcp`

Проверка состояния: `https://<your-worker>.workers.dev/health`

## Ограничения

- Это не генератор готовых MP4/WebM-файлов: инструмент формирует только JSON-проект.
- Удаление виджета не гарантирует работу пользовательского MCP-сервера в Android-приложении ChatGPT. Поддержка таких подключений зависит от самого ChatGPT и может быть ограничена веб-версией.
- Эта ветка экспериментальная; основная ветка `main` не меняется.
